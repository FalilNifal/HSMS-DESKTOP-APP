# HSMS Desktop App

HSMS Desktop App is a Windows-based offline hardware store management system designed for local shop use. It supports inventory management, suppliers, POS billing, invoice printing, profit tracking, user roles, and backup/restore.

## Main Features

- Windows desktop installation
- Offline local database
- First-time admin setup
- Role-based login system
- Product and stock management
- Supplier management
- POS billing
- Editable selling price during billing
- Minimum selling price protection
- Purchase price and profit tracking
- Invoice/bill printing
- Sales and profit reports
- Backup and restore

## Technology Plan

- Frontend: React + TypeScript
- Desktop App: Electron
- Backend: ASP.NET Core
- Database: SQLite
- Installer: Windows installer
